## Direction findings

2026-07-20 のメンテナフィードバックにより全件クローズ。監査の方向性提案は 3 件とも不採用:

1. **プレゼンタービュー** — 監査の誤認。ノート常時表示（左側）+ スライド操作の画面は Workspace として最初から実装済み。slideshow ルートだけを見て「ノートが見えない」と判断したのが誤り。
2. **静的ビルドの serve/preview** — メンテナ判断で不要。
3. **PDF 以外のスライドソース** — `Slides` インターフェースのソース非依存設計は **将来の ppt 対応のための意図的な備え**（メンテナ確認済み、[ADR-0012](../docs/adr/0012-source-agnostic-slides-interface-for-ppt.md) に記録）。「需要不明の抽象」ではない。ppt 対応自体はメンテナのロードマップ事項であり、監査からの提案対象ではない。

## Findings considered and rejected

- **CLI CORRECTNESS-04（`httpServer close` 時の async `close()` の unhandled rejection）**: 単独プランにする価値なし。Plan 003 の Step 3 に同梱済み。
- **`pnpm audit` の cookie <0.7.0（low、@sveltejs/kit 経由・ビルドパスのみ）**: runtime 到達性なし、low severity。対応不要。
- **`- - -` スペース混在セパレータ非対応・`*`/`_` 非対応**: ADR-0006 で意図的に絞り込み済み。by-design。
- **ワイヤ型・セパレータ判定・`nfp:slides-changed` 定数の 2 パッケージ重複**: ADR-0002/0003/0008 で決定済みのトレードオフ。
- **PDF 縮小時の active スライド未クランプ**: ADR-0008 で明示的に見送り済み。
- **`--host` 公開時の無認証 API**: ローカルツールの by-design（ユーザーが明示的に opt-in するフラグ）。
- **knip 検出の dead code / TODO・FIXME クラスタ**: ゼロ件（確認済み）。
- **phosphor-svelte の全量 import / 画像の lazy-load 欠如 / decoration 毎キーストローク再計算**: いずれも既に対応済みだった（per-icon import、`loading="lazy"`、`tr.docChanged` ガード）。
- **プレゼンタービュー / serve コマンド / スライドソース追加（Direction 全 3 件）**: 2026-07-20 メンテナフィードバックで不採用（詳細は Direction findings 欄）。次回監査で再提案しないこと。
