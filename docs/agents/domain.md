# Domain Docs

- 探索を始める前に、リポジトリルートの **`CONTEXT.md`**（用語集）と、作業する領域に触れる **`docs/adr/`** を読むこと。
- 出力（issue タイトル・リファクタ提案・テスト名など）でドメイン概念を指すときは、`CONTEXT.md` の定義どおりの語を使うこと。用語集が意図的に避けている同義語に流れない。必要な概念が用語集に無ければ、それは「プロジェクトに無い言語を発明している」か「本当の欠落」かのどちらかのシグナル。
- 出力が既存の ADR と矛盾する場合は、黙って上書きせず明示すること（例: _ADR-0017 と矛盾するが、再検討に値する理由は…_）。
